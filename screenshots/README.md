## How to capture them

1. Start MongoDB (or use Atlas), then run the backend and frontend as described in the root `README.md`.
2. Open http://localhost:5173 in your browser.
3. **Add:** type a task, click **Add Task**, and capture the page with the new task visible.
4. **Complete:** tick the checkbox of a task and capture the strikethrough result.
5. **Delete:** click **Delete** on a task and capture the page once it has disappeared. Capturing a short sequence (before and after) also works.
6. **Merged pull requests:** on GitHub open your repository, choose **Pull requests**, click the **Closed** tab, and capture the page showing your merged backend and frontend pull requests (purple "Merged" icons).
7. Save the four images in this folder using the filenames above, then update the Status column to "Done".

Do not use mock-ups or edited images; they do not count as evidence.
